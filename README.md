# 👨‍💻 智能内容生成 Agent

这是一个功能强大的内容处理 Agent，旨在将视频、音频或文本文档自动转换为结构化、高质量的 Markdown 笔记。

本应用集成了一个 Streamlit 交互界面，允许用户上传文件，使用 Qwen ASR 云端转录，并根据内容类型（理工科STEM、 人文社科HASS或医学Medical）调用大语言模型（LLM）生成深度定制的笔记。

## 核心功能

* **多模态输入**: 支持多种文件格式：
    * **视频**: `.mp4`, `.mov`, `.webm` 等 (由 FFmpeg 支持)。
    * **音频**: `.mp3`, `.m4a`, `.wav`, `.mpga` 等。
    * **文档**: `.txt`, `.md`, `.pdf` 等。
* **云端语音转录**: 调用阿里云 DashScope 提供的 Qwen ASR 模型。
* **ASR 上下文增强**: 在使用 Qwen API 时，可提供“热词”（如专业术语、人名）来显著提升特定词汇的识别准确率。
* **智能笔记生成**: 利用配置的大语言模型（LLM）将转录稿或文本文档处理成笔记：
* **笔记精炼 (Refine)**: 支持对已生成的笔记进行迭代修改。用户可以提出“更简洁”、“更详细”或自定义指令，Agent 将结合原始转录稿重新生成笔记。
* **实时流式输出**: 在生成和精炼笔记时，支持流式（Streaming）输出，内容逐字显示，提供即时反馈。
* **配置验证**: 通过界面的模型连通性检测检查 API 密钥和网络连接。

## 技术栈

* **前端框架**: Streamlit
* **媒体处理**: FFmpeg (通过 `subprocess` 调用)
* **核心依赖**: Python 3.x
* **ASR (语音转录)**: `dashscope`
* **LLM API**: `requests` (兼容 OpenAI 格式的 API), `dashscope`
* **配置管理**: `python-dotenv`

## 输出、并发与停止

每次生成使用独立的 `temp/tasks/<任务ID>` 临时目录和 `output/<笔记名>_<任务ID>` 输出目录。
不同窗口的运行配置单独保存，任务启动时取得配置快照；同名笔记不会覆盖已有输出。
勾选“保留语音转文字稿”后，文字稿与笔记一起写入本次输出目录，下一次生成或关闭应用不会删除它。
勾选保留视觉中间文件后，关键帧位于本次输出目录的 `frames` 中。

停止按钮取消排队任务、中断重试等待并终止媒体处理子进程。已发送的云端请求不能撤回；
后台在当前请求返回或超时后退出并清理自己的临时文件，不再保存后续结果。
临时网络错误、限流和部分服务端错误每个模型最多尝试三次；认证、参数和文件错误不重试。

## 本地配置

将 `.env.example` 复制为 `.env`，填写自己的密钥。`.env` 不纳入 Git 跟踪。
配置文件属于本机默认设置，运行中的任务使用独立快照。历史 Git 提交中的内容不会因忽略规则自动移除。

## 动态模型列表

输入 API Key 后，验证页和侧边栏会自动查询对应百炼地址的模型目录。两处均提供“刷新模型列表”按钮。
目录按 Key 与服务地址隔离缓存，缓存有效期为 24 小时，保存在 Git 忽略的 `.cache/model_catalog` 中，不存储密钥。
完整分页同步成功后才更新列表；网络、权限或分页异常时保留上次成功缓存，没有缓存时使用 `models.json`。
同步失败后的自动重试间隔为 5 分钟，手动刷新不受此间隔限制。

模型按用途和现有调用接口筛选；当前自动发现的 ASR 限于 Qwen3-ASR-Flash 系列，避免将实时或异步 ASR 模型用于同步接口。
某分类没有兼容结果时会提示并保留本地列表。手动管理仍可兜底，但下一次成功同步可能覆盖手动调整。
官方下线信息会显示在模型名称旁；目录中不存在的模型会在成功同步时移出相应的已更新分类。

同步只读取目录，不调用生成模型，也无法判断账户剩余免费额度。进入页面不再自动调用旧模型做启动验证；
仅点击“验证并保存”时验证所选模型。403 免费额度耗尽会单独提示，不再显示为未知错误。
标准接口和分页字段见[百炼官方模型目录文档](https://help.aliyun.com/zh/model-studio/list-models)。
按量付费 API 的地域及业务空间由 `.env` 中的 `LLM_BASE_URL` 决定；Token Plan 等独立服务地址暂不自动同步。
